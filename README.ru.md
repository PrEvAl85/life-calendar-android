Приложение **Life Calendar** для Android показывает всю вашу жизнь в виде сетки недель — от даты рождения до конца ожидаемой продолжительности жизни. Удобный обзор по десятилетиям и годам, журнал записей, события и статистика. Все данные хранятся локально на вашем устройстве.

Основано на идее [Life in Weeks](https://waitbutwhy.com/2014/05/life-weeks.html) от WaitButWhy.

## Возможности

### Вкладки

Приложение состоит из 5 вкладок (нижняя навигация):

- **Сегодня** — экран текущей недели: записи и события, навигация между соседними неделями (← →), кнопка «Сегодня».
- **Карта** — обзор всей жизни: переключатель **«10 лет | Год»**.
- **Дневник** — все записи единым списком: сначала новые, поиск по тексту, создание/редактирование/удаление.
- **События** — список событий с цветами; **«День рождения» закреплён вверху** (автоматически, из даты рождения в настройках).
- **Профиль** — жизненная статистика + все настройки + резервная копия на одном экране.

### Карта: режим «10 лет»

- Карточки десятилетий начиная с года рождения: «1985–1994», «1995–2004», … (последняя — неполная).
- В каждой карточке **4 ряда объявлений**: сначала события (цветная точка + дата + название), затем записи (дата + текст). Если объявлений больше — «+N ещё…».
- **Ваш день рождения автоматически появляется в событиях** года рождения (зелёным, без записи в базе данных).
- Нажмите на десятилетие → внутри карточки годов. В каждой карточке: **«Год — возраст»** с правильными словоформами («1991 — 6 лет», «2026 — 41 год», год рождения — «1985 — рождение», будущее — «2031 — 46 лет · будущее»).
- Нажмите на год → раздел «Год» для этого года.

### Карта: режим «Год»

- Карточки всех недель выбранного года, сгруппированные по месяцам с **«липкими» заголовками «Январь»…«Декабрь»**.
- В каждой карточке: даты недели, события в виде цветных точек, превью записей, подсветка «сегодня».
- Нажмите на неделю → панель с подробностями.
- Нажмите «Год 2026» → быстрый выбор любого года от рождения до текущего.

### Панель недели (BottomSheet)

Нажатие на прожитую неделю на карте/в году открывает панель: даты недели, кнопка **«Открыть неделю»** (на весь экран), **«Добавить запись»** и разделы «События» и «Записи» (нажмите на запись, чтобы отредактировать, значок корзины — чтобы удалить).

### Будущее недоступно

- Нажатия на будущие недели игнорируются; в режиме «Год» они затемнены и помечены как «Будущее».
- Кнопка добавления записи скрыта на будущих неделях; выбор будущих дат в календаре записи запрещён.

### Прочее

- **Онбординг при первом запуске**: спрашивает дату рождения, прежде чем вы начнёте.
- **Резервная копия**: экспорт всех данных в JSON (и импорт обратно) через системный диалог сохранения/открытия файла.
- **Тёмная и светлая темы** — следуют за системой.
- **Многоязычность**: язык приложения следует за регионом устройства (17 переводов плюс английский) и может быть изменён вручную в Профиль → Язык.
- Все данные хранятся только локально (Room + DataStore), интернет не используется.

## Начало работы

### Первый запуск

1. Установите APK (см. «Установка» ниже).
2. Приложение попросит вас указать **дату рождения** — этот шаг обязателен. На ней основаны все расчёты: десятилетия, возраст на карточках годов, статистика.
3. Вы можете изменить её в любое время в **Профиль → Дата рождения**.

### Повседневное использование

- **Сделать запись за сегодня** — три способа:
  - вкладка **«Сегодня»** → кнопка «+» (FAB);
  - вкладка **«Дневник»** → кнопка «+» (FAB);
  - **«Карта»** → нажмите нужную неделю → «Добавить запись».
- **Найти старую запись** — вкладка **«Дневник»**, поиск по тексту.
- **Добавить событие** (день рождения друга, годовщину и т. п.) — вкладка **«События»** → кнопка «+» → название, цвет, дата.
- **Узнать, что было 10 лет назад** — **«Карта»** → режим «10 лет» → нажмите на десятилетие «1995–2004» → нажмите на нужный год → раздел «Год» для этого года, или сразу посмотрите объявления на карточке года.
- **Оценить свой жизненный прогресс** — вкладка **«Профиль»**: возраст (лет/недель), процент прожитой жизни, оставшиеся недели, количество записей и событий.
- **Перенести данные на другое устройство** — **Профиль → Резервная копия**: экспорт JSON → отправьте файл → импортируйте JSON на новом устройстве.

### Что означают цвета и подписи

- Зелёная точка — «День рождения» (всегда виртуальный, не может быть удалён).
- Точки других цветов — ваши события; цвет выбирается при создании.
- Строки без точки в карточках «10 лет» — записи дневника.
- «+N ещё…» — не всё помещается в карточку, откройте карточку года/десятилетия.
- «· будущее» на карточке года — год ещё не наступил; до этого его объявления пусты.

## Установка

1. Скачайте файл `life-calendar-vX.Y.Z.apk` из [Releases](https://github.com/PrEvAl85/life-calendar-android/releases).
2. Откройте файл на устройстве и подтвердите установку из неизвестных источников (система предложит это).

### Play Protect и неподписанный APK

APK не подписан Google Play и не прошёл проверку Google Play Protect — при первой установке Android может показать предупреждение «Play Protect заблокировал приложение» или попросить подтвердить установку. Файл безопасен: это сборка открытого исходного кода этого репозитория.

- Как установить: в диалоге Play Protect выберите **«Подробнее» → «Всё равно установить»** (однократно), либо в настройках Android: **Безопасность → Установка неизвестных приложений → разрешить** для вашего файлового менеджера/браузера.
- Скачивайте APK только из раздела **Releases** этого репозитория.

## Сборка из исходников

Требования: JDK 17, Android SDK (compileSdk 35), Gradle 8.10.2 (репозиторий включает wrapper).

```
gradlew assembleRelease
```

Подписанный APK появится по адресу `app/build/outputs/apk/release/app-release.apk`.

Примечание: если путь проекта содержит не-ASCII символы, Gradle может отказаться собирать (`StopExecutionException: ... non-ASCII characters`). Флаг `android.overridePathCheck=true` уже добавлен в `gradle.properties`, что решает эту проблему.

## Структура проекта

- `app/src/main/java/com/prev85/lifecalendar/`
  - `MainActivity.kt` — точка входа, обработчик необработанных исключений (лог в `filesDir/crash.log`).
  - `ui/AppNav.kt` — навигация и нижняя панель с 5 вкладками (Сегодня · Карта · Дневник · События · Профиль).
  - `ui/grid/` — вкладка «Карта»:
    - `DecadeOverviewScreen.kt` — карточки десятилетий и годов с объявлениями и возрастами;
    - `YearOverviewScreen.kt` — обзор года по месяцам со `stickyHeader`;
    - `YearPickerSheet.kt` — быстрый выбор года;
    - `WeekDetailSheet.kt` — панель недели (события/записи/открыть неделю);
    - `WeekGridViewModel.kt` — состояние: недели, события, записи, настройки.
  - `ui/entries/` — вкладка «Дневник»: все записи, поиск, CRUD.
  - `ui/events/` — вкладка «События»: список с цветами, закреплённый «День рождения».
  - `ui/profile/` — вкладка «Профиль»: статистика + настройки + резервная копия.
  - `ui/onboarding/` — первый запуск: запрос даты рождения.
  - `ui/week/` — экран недели (вкладка «Сегодня» и навигация с карты).
  - `ui/common/` — общий диалог записи, диалог выбора даты, общие цвета (например, зелёный для «Дня рождения»).
  - `util/LanguageManager.kt` — управление языком приложения (регион устройства + ручной выбор в Профиле).
  - `data/` — Room (сущности, DAO, база данных), DataStore (настройки), `BackupManager.kt` (резервная копия JSON).
  - `util/Dates.kt` — математика дат и недель.
