# Life Calendar (Календарь жизни)

Android-приложение «Календарь жизни»: вся жизнь в виде недель — от вашего дня рождения до конца ожидаемой продолжительности жизни. Удобный обзор по десятилетиям и годам, дневник записей, события, статистика. Всё хранится локально на устройстве.

Основано на идее [Life in Weeks](https://waitbutwhy.com/2014/05/life-weeks.html) из WaitButWhy.

## Возможности

### Вкладки

Приложение состоит из 5 вкладок (нижняя навигация):

- **Сегодня** — экран текущей недели: записи и события, навигация по соседним неделям (← →), кнопка «Сегодня».
- **Карта** — обзор всей жизни: переключатель **«10 лет | Год»**.
- **Дневник** — все записи единым списком: свежие сверху, поиск по тексту, создание/редактирование/удаление.
- **События** — список событий с цветами; **«День рождения» закреплён вверху** (автоматически, из даты рождения в настройках).
- **Профиль** — статистика жизни + все настройки + бэкап в одном экране.

### Карта: режим «10 лет»

- Карточки десятилетий от года рождения: «1985–1994», «1995–2004», … (последняя частичная).
- В каждой карточке — **4 строки анонсов**: события (цветной кружок + дата + название) сначала, затем записи (дата + текст). Если анонсов больше — «+N ещё…».
- **День рождения автоматически появляется в событиях** года рождения (зелёным, без записи в базу).
- Тап по декаде → карточки годов внутри неё. Каждая карточка: **«Год — возраст»** со склонениями («1991 — 6 лет», «2026 — 41 год», год рождения — «1985 — рождение», будущие — «2031 — 46 лет · будущее»).
- Тап по году → раздел «Год» на этот год.

### Карта: режим «Год»

- Карточки всех недель выбранного года, сгруппированы по месяцам с **липкими заголовками «Январь»…«Декабрь»**.
- В каждой карточке: даты недели, события цветными кружками, превью записей, подсветка «сегодня».
- Тап по неделе → панель с деталями.
- Клик по «Год 2026» → быстрый выбор любого года от рождения до текущего.

### Панель недели (BottomSheet)

Тап по прожитой неделе на карте/в году открывает панель: даты недели, кнопка **«Открыть неделю»** (полный экран), **«Добавить запись»**, секции «События» и «Записи» (клик по записи — редактирование, иконка корзины — удаление).

### Будущее недоступно

- Тап по будущим неделям игнорируется; в режиме «Год» они затемнены с пометкой «Будущее».
- Кнопка добавления записи скрыта на будущих неделях; выбор будущих дат в календаре записи запрещён.

### Прочее

- **Онбординг при первом запуске**: запрос даты рождения до начала работы.
- **Бэкап**: экспорт всех данных в JSON (и импорт обратно) через системный диалог сохранения/открытия файла.
- **Тёмная и светлая темы** — следуют за системой.
- Все данные только локально (Room + DataStore), интернет не используется.

## Как пользоваться

### Первый запуск

1. Установите APK (см. «Установка» ниже).
2. Приложение попросит указать **дату рождения** — это обязательный шаг. От неё строятся все расчёты: десятилетия, возраста на карточках годов, статистика.
3. Дальше приложение можно менять в любой момент в **Профиль → Дата рождения**.

### Ежедневное использование

- **Сделать запись на сегодня** — три способа:
  - вкладка **Сегодня** → кнопка «+» (FAB);
  - вкладка **Дневник** → кнопка «+» (FAB);
  - **Карта** → тап по нужной неделе → «Добавить запись».
- **Найти старую запись** — вкладка **Дневник**, поиск по тексту.
- **Добавить событие** (день рождения друга, годовщина и т.п.) — вкладка **События** → кнопка «+» → название, цвет, дата.
- **Посмотреть, что было 10 лет назад** — **Карта** → режим «10 лет» → тап по декаде «1995–2004» → тап по нужному году → «Год» на этот год, либо сразу просмотр анонсов на карточке года.
- **Оценить прогресс жизни** — вкладка **Профиль**: возраст (лет/недель), процент прожитой жизни, остаток недель, число записей и событий.
- **Перенести данные на другое устройство** — **Профиль → Бэкап**: экспорт JSON → переслать файл → на новом устройстве импорт JSON.

### Что означают цвета и пометки

- Зелёный кружок — «День рождения» (всегда виртуальный, его нельзя удалить).
- Кружки остальных цветов — ваши события, цвет выбирается при создании.
- Строки без кружка в карточках «10 лет» — записи дневника.
- «+N ещё…» — в карточке поместилось не всё, откройте карточку года/декады.
- «· будущее» на карточке года — год ещё не наступил, анонсы в нём пусты до наступления.

## Установка

1. Скачайте `life-calendar-vX.Y.Z.apk` из [Releases](https://github.com/PrEvAl85/life-calendar-android/releases).
2. Откройте файл на устройстве и подтвердите установку из неизвестных источников (система подскажет).

### Play Protect и неподписанный APK

APK не подписан Google Play и не прошёл проверку Google Play Protect — при первой установке Android может показать предупреждение «Play Protect заблокировал приложение» или попросить подтвердить установку. Файл безопасен: это сборка из открытого исходного кода этого репозитория.

- Как установить: в диалоге Play Protect выберите **«Подробнее» → «Всё равно установить»** (одноразово), либо в настройках Android: **Безопасность → Установка неизвестных приложений → разрешить** для файлового менеджера/браузера.
- Скачивайте APK только из раздела **Releases** этого репозитория.

## Сборка из исходников

Требования: JDK 17, Android SDK (compileSdk 35), Gradle 8.10.2 (в репозитории есть wrapper).

```
gradlew assembleRelease
```

Подписанный APK появится в `app/build/outputs/apk/release/app-release.apk`.

Примечание: если путь к проекту содержит кириллицу, Gradle может отказаться собирать (`StopExecutionException: ... non-ASCII characters`). В `gradle.properties` уже добавлен флаг `android.overridePathCheck=true`, решающий эту проблему.

## Структура проекта

- `app/src/main/java/com/prev85/lifecalendar/`
  - `MainActivity.kt` — точка входа, обработчик необработанных исключений (лог в `filesDir/crash.log`).
  - `ui/AppNav.kt` — навигация и нижняя панель из 5 вкладок (Сегодня · Карта · Дневник · События · Профиль).
  - `ui/grid/` — вкладка «Карта»:
    - `DecadeOverviewScreen.kt` — карточки десятилетий и годов с анонсами и возрастом;
    - `YearOverviewScreen.kt` — годовой обзор по месяцам со `stickyHeader`;
    - `YearPickerSheet.kt` — быстрый выбор года;
    - `WeekDetailSheet.kt` — панель недели (события/записи/открыть неделю);
    - `WeekGridViewModel.kt` — состояние: недели, события, записи, настройки.
  - `ui/entries/` — вкладка «Дневник»: все записи, поиск, CRUD.
  - `ui/events/` — вкладка «События»: список с цветами, закреплённый «День рождения».
  - `ui/profile/` — вкладка «Профиль»: статистика + настройки + бэкап.
  - `ui/onboarding/` — первый запуск: запрос даты рождения.
  - `ui/week/` — экран недели (вкладка «Сегодня» и переход с карты).
  - `ui/common/` — общий диалог записи, диалог выбора даты, общие цвета (например, зелёный для «Дня рождения»).
  - `data/` — Room (entities, DAO, база), DataStore (настройки), `BackupManager.kt` (JSON-бэкап).
  - `util/Dates.kt` — работа с датами и неделями.
