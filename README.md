# Life Calendar (Календарь жизни)

Android-приложение «Календарь жизни»: вся жизнь в виде сетки недель — 52 колонки (недели) на каждый год от вашего дня рождения до 100 лет. Прожитые недели — серые, будущие — светлые, недели дня рождения — зелёные, недели с заметками помечены точкой, события — цветным прямоугольником.

Основано на идее [Life in Weeks](https://waitbutwhy.com/2014/05/life-weeks.html) из WaitButWhy.

## Возможности

- Сетка «жизнь в неделях» как в Obsidian: каждый год — строка из 52 сердечек ♥ (прожитые — красные, будущие — серые, недели дня рождения — зелёные, события — в своём цвете, недели с записями отмечены жёлтой точкой, текущая неделя — красная рамка).
- Бесшовный pinch-зум в точку касания: приближайте район любых дат — сердечки растут, появляются даты недель и превью записей; на максимальном зуме неделя разворачивается в обзор 7 дней с текстами записей и событиями.
- Недельный обзор: тап по записи — редактирование, тап по пустому дню или кнопка «+» — новая запись; панорамирование листает соседние недели.
- Двойной тап — полный вид всей жизни; кнопка «Сегодня» — приближение к текущей неделе.
- События: список с цветами, отображаются на сетке.
- Статистика: прожито лет/месяцев/дней, процент прожитой жизни, осталось недель.
- Настройки: дата рождения, ожидаемая продолжительность жизни (50–120 лет), экспорт/импорт всех данных в JSON.
- Все данные хранятся только локально на устройстве (Room + DataStore). Ничего не отправляется в интернет.
- Тёмная и светлая темы.

## Установка

1. Скачайте `life-calendar-vX.Y.Z.apk` из [Releases](https://github.com/PrEvAl85/life-calendar-android/releases).
2. Откройте файл на устройстве и подтвердите установку из неизвестных источников (система подскажет).

### Windows SmartScreen и неподписанный APK

APK не подписан Google Play и не прошёл проверку Google Play Protect — при первой установке Android может показать предупреждение «Play Protect заблокирован приложение» или попросить подтвердить установку. Файл безопасен: это сборка из открытого исходного кода этого репозитория.

- Как установить: в диалоге Play Protect выберите **«Подробнее» → «Всё равно установить»** (одноразово), либо в настройках Android: **Безопасность → Установка неизвестных приложений → разрешить** для файлового менеджера/браузера.
- Скачивайте APK только из раздела **Releases** этого репозитория.

## Сборка из исходников

Требования: JDK 17, Android SDK (compileSdk 35), Gradle 8.10.2 (в репозитории есть wrapper).

```
gradlew assembleRelease
```

Подписанный APK появится в `app/build/outputs/apk/release/app-release.apk`.

Примечание: если путь к проекту содержит кириллицу, Gradle может отказаться собирать (`StopExecutionException: ... non-ASCII characters`). В `gradle.properties` уже добавлен флаг `android.overridePathCheck=true`, решающий эту проблему.

## Структура проекта

- `app/src/main/java/com/prev85/lifecalendar/`
  - `MainActivity.kt` — точка входа, навигация (`grid`, `week/{monday}`, `events`, `stats`, `settings`).
  - `ui/grid/` — экран сетки недель: сердечки с LOD-зумом (Compose Canvas), `WeekOverview.kt` — развёрнутая неделя (7 дней).
  - `ui/common/` — общий диалог записи.
  - `ui/events/` — список событий с цветами.
  - `ui/stats/` — статистика жизни.
  - `ui/settings/` — настройки, экспорт/импорт.
  - `data/` — Room (entities, DAO, база), DataStore (настройки), `BackupManager.kt` (JSON-бэкап).
  - `util/Dates.kt` — работа с датами и неделями.
